# AI Interviewer

AI Interviewer is an AI-powered interview preparation platform that helps candidates practice personalized interviews based on their resume and target job description.

## Features

- User authentication
- Resume upload and analysis
- Job description analysis
- AI-generated interview questions
- Technical and behavioral interview questions
- AI-based answer evaluation
- Voice-based interview interaction
- Interview feedback and performance analysis
- Job matching based on resume and job description

## Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Gemini AI
